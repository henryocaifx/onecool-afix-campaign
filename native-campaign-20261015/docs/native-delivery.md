# Native-file delivery

No finishing, transcoding or post-editing is used for this batch. The received BytePlus MP4 bytes are the deliverable. The generation request is 30 seconds, nominal 1080p, 21:9, synchronized audio. Exact returned codec, dimensions, frame count, video/audio/container durations, and loudness are reported as returned.

Native Seedance 1080p ultrawide is documented as 2206 × 946 and can be HEVC/10-bit. Files are not converted to H.264 or resized to 2520 × 1080. Native endpoint timing may include a final video frame or audio encoder tail beyond the nominal 30-second request. The user's direct-upload instruction takes precedence over earlier exact-frame finishing requirements.

The only intended readable mark is the authentic ONE COOL / AIFX logo on a physical equipment case. No title, subtitle, caption, text box, UI overlay, credit, added watermark, or text end card is requested. All actors are original adult humans. References use environments, wardrobe seen from the back, and the actual logo rather than real-person face inputs.

Submission and polling reuse `../scripts/byteplus_jobs.py` from the repository root with `--project-root native-campaign-20261015`. Ledger files prevent duplicate submissions. Native video hashes are verified before upload and after signed-URL readback. Frames extracted for review/posters do not alter the source video.

R2 objects use a new unique prefix while the first campaign's objects and download service remain intact. The previously approved exact-file signed Worker delivery method is reused for the four new MP4s; no bucket public access is enabled.
