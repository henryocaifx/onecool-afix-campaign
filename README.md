# AIFX Studio · Make room for your imagination

Production workspace for four original 30-second campaign films, commissioned in the attached brief. Work in progress; no film is claimed delivered until its technical and R2 checks pass.

| Film | Format | Creative identity |
| --- | --- | --- |
| 01 — The Little Idea That Escaped | Storytelling short | Handmade amber-and-teal adventure |
| 02 — Deadline: Impossible | Storytelling short | Fast, colorful studio comedy |
| 03 — The Last Spark | Movie trailer | Monumental monochrome-to-color science fantasy |
| 04 — The Imagination Heist | Movie trailer | Magenta-and-cyan caper with a comic sting |

See [the scripts](docs/scripts.md), [product research](docs/product-research.md), and [production specification](docs/production.md). Assets, generation records, source clips, exports, and delivery records remain separate. Large final/source videos are delivered through R2 rather than regular Git objects. Never commit credentials, temporary access tokens, or signed provider result URLs.

Milestone commits are pushed to `main` in `henryocaifx/onecool-afix-campaign`, as requested.
